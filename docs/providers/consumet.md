# Consumet Provider

* **Origem**: Repositório consumet/api.consumet.org
* **URL**: Auto-Hospedado (`process.env.CONSUMET_URL`)
* **Licença**: MIT
* **Integração**: REST API
* **Idioma**: Misturado, exige parse profundo ou uso do filtro interno `LanguageFilter`.
* **Rate Limit**: Depende da instância self-hosted.
* **Status**: DEGRADED/OFFLINE (Aguardando Deploy do container)
* **Limitações**: A API pública principal do Consumet saiu do ar, obrigando-nos a usar Docker.
